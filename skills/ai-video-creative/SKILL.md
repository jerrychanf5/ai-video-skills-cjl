# AI 视频创意发散（Skill A）

> 定位：帮用户打开思路，产出**供离线讨论的创意备选方案**。
> 用户不需要当场拍板——拿去讨论后再决定，再交 ai-video-prompt 生成提示词。
> 知识源：`../../产物/5-AI视频创作通用手册-第二版.md`（第四部分：13 种形态 / 12 种风格 / 叙事结构 / 技法概览）
> 案例库：预留接口（阶段 2 接入极空间 MCP，当前跳过，遇到"找参考案例"请求直接说明）

## 需要的信息（越多越准，缺了不追问，先输出再提示）

| 信息 | 作用 |
|---|---|
| 视频主题/项目简述（尽量提供） | 判断叙事方向 |
| 目标受众（可选） | 调整情绪基调 |
| 本次诉求——曝光/留资/转化（可选） | 影响叙事结构和 CTA |
| 现有素材描述（可选） | 评估方向可行性，标注缺口 |

信息不足时：先用已有信息输出，在文末注明"补充以下信息可让建议更准确：……"

## 工作流程

### 第 1 步：从形态和风格谱系中发散

读手册第二版第四部分（4.1-4.4），按用户信息匹配 **2-3 个方向**。

每个方向包含：

- **形态名称**（如：场景沉浸式 / 微剧情式 / 节奏卡点式）
- **一句话感受**：看这条视频时，观众会有什么感受、什么情绪——让用户凭直觉选，不用看技术说明
- **风格定调**：视觉质感（电影感 / 生活温馨 / 快节奏等）
- **叙事草案**：大概几段，什么逻辑（如：钩子 3秒 → 卖点 4段 → CTA 5秒）
- **素材提示**：需要什么类型的画面；用户提供了素材清单时，标出哪些已有、哪些缺

### 第 2 步：以自由文字格式输出创意参考

**不输出结构化表单**，输出自然语言备忘录（供截图/打印/发同事讨论）：

```
# [主题] · 创意方向参考

## 方向一：[形态名称]
感受：……
风格：……
叙事草案：……
素材需求：……（已有：…… / 缺：……）

## 方向二：[形态名称]
……

---
确定方向后，把你选的方案发给 ai-video-prompt，帮你转成可直接使用的提示词。
```

## 硬停止

- 用户说"已经想好了，帮我写提示词" → 停止，告知转用 `ai-video-prompt`
- 用户提供了具体镜头描述 + 底图说明，信息已足够写提示词 → 停止，告知转用 `ai-video-prompt`

---

## 红线

- 不替用户做决策：输出是参考材料，选哪个方向由用户自己决定
- 不强制多样性检查：不要求用户提供历史视频，不做"上条做过什么"的校验
- 不固化行业假设：方法论通用，不预设"这类项目应该怎样拍"
- 不写具体数字：价格/面积/距离等一律留空或标"后期字幕处理"
